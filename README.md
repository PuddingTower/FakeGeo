# 拟境（FakeGeo）

拟境是一款免费开源的 Android 环境模拟工具，面向已 Root、安装 LSPosed 的 Android 10 及以上设备。它不只改一个坐标，还可以把目标场所的 Wi-Fi、蓝牙广播和基站指纹采集下来，清洗成可复用的环境，再通过系统服务 Hook 无感回放。

## 功能介绍

- 地图拖动选点、地址搜索，一键开启或停止虚拟定位。
- 在目标场所一次性采集 Wi-Fi、BLE 广播、LTE/NR 小区和坐标，自动去噪、聚合、保留锚点。
- 本地环境指纹库：保存多个场所，一键应用，不再手写 BSSID、蓝牙 MAC 或广播十六进制。
- 回放多 AP 扫描列表、BLE 广播（含 Service UUID、Manufacturer Data 和原始字节）以及 LTE/NR 小区身份。
- 定位漂移、更新间隔、Wi-Fi 连接状态等参数仍可在高级设置微调。
- 选择应用，手动清除支持的高德／百度定位缓存，并恢复最近备份。
- 首次使用引导、Root 授权、系统 Hook 状态检测和 GitHub 更新检查。

采集只在前台运行约 22 秒，结束自动停止；BLE 回放频率跟随目标 App 的 `ScanSettings`（低延迟 1 秒、均衡 2 秒、低功耗 5 秒），没有后台常驻扫描。

部分 App 不生效，发现问题请提交 [Issue](https://github.com/myxuebi/FakeGeo/issues)。

## 使用说明

### 首次配置

1. 在已 Root 的设备安装拟境，阅读并同意首次声明，按引导完成配置。
2. 点击请求 Root 授权，在 KernelSU 或其他 Root 管理器中允许拟境。
3. 在 LSPosed 启用模块，勾选 Android 系统／系统框架、电话服务、蓝牙，以及设备提供的独立 Wi-Fi 服务作用域，然后重启手机。
4. 在高级设置的“高德地图与搜索设置”填写自己的 **高德 Android SDK Key**。绑定包名 `io.github.fakegeo` 和该页面显示的当前签名 SHA1，同意高德服务后保存。
5. 保持系统定位开启，检测系统 Hook 状态，确认已加载并同步。

### 环境采集与回放

先停止虚拟环境，再打开首页右上角的环境指纹入口（或高级设置里的“环境采集与指纹库”）。点击“采集当前环境”，授予定位、蓝牙和附近的 Wi-Fi 设备权限，等待约 22 秒。采集完成后可以命名、保存并立即应用。

应用环境会同时设置坐标、Wi-Fi 扫描列表、蓝牙广播和基站字段；采集时若手机正连着目标 AP，会同时打开 Wi-Fi 连接标志。想更换场所时重新采集即可；同一场所可以保存多份环境。

BLE 多设备回放只在应用兼容模式生效，需要把目标应用加入作用域并关闭系统模式。系统模式下会回放 Wi-Fi 和基站，但蓝牙仍只做隔离。

### 地图定位

在首页搜索地址并选择结果，或拖动地图将准星移到目标地点，点击“开启虚拟定位”。修改选点后点击“应用新位置”；点击停止按钮结束虚拟定位。应用过环境后，地图选点只改变坐标，不会清掉已采集的无线指纹。

“真实位置”需要精确定位权限和可用的 GPS 信号，只调整准星，不自动改变已发布的虚拟位置。GPS 无信号时请到开阔位置重试。

### 高级设置

定位精度、更新间隔、漂移半径，以及 Wi-Fi、蓝牙、基站等参数在高级设置调整，保存并应用后生效。应用环境后，无线列表优先使用环境库，单值字段只作为回退。

若应用使用旧的定位缓存，可选择该应用并点击“清除所选应用的定位缓存”。清理会关闭所选应用，保留可恢复备份，仅处理支持的定位缓存文件；没有匹配文件时不清空应用数据。恢复最近备份前需停止虚拟定位。

高级设置底部可查看关于、使用声明和首次引导，点击“检查更新”获取 GitHub 最新正式 Release。地图与地址搜索需要网络和有效的高德 Key。
